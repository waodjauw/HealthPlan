# HealthPlan · UI 设计规范

> 与 `PROJECT_SPEC.md` 配套。第一版 UI 稿的设计决策与视觉 token 都在这里，开发时直接对照。

---

## 1. 设计原则

1. **记录要快**：从打开 App 到记完一条，目标 3 次点击以内。
2. **数字优先**：热量和碳蛋脂是主角，视觉重心永远给数字。
3. **不做图表轰炸**：只有一个环形图（供能比），其余用进度条。
4. **亮暗等价**：暗色不是把亮色反色，是不同的色阶。

## 3. 字体与字号

- 字体：`-apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`
- 字重只用两种：**400 常规 / 500 中等**。禁止 600/700。
- 数字统一用等宽数字特性（`font-variant-numeric: tabular-nums`），避免跳动。

| 层级 | 字号 | 用途 |
|---|---|---|
| 大数字 | 26px（手机）/ 21px（桌面） | 当日总热量 |
| 标题 | 15px | 页面标题、食物名 |
| 正文 | 13px | 食物条目名称 |
| 次要 | 12px | 份量、小计 |
| 辅助 | 11px | 单位、每 100g 数据 |
| 最小 | 10px | 营养明细行 |

## 4. 响应式断点

| 断点 | 布局 | 说明 |
|---|---|---|
| `< 768px` | 单栏 | 汇总吸顶，餐次纵向排列，底部悬浮 + 按钮 |
| `768 ~ 1199px` | 双栏 `5 : 4` | 左记录区 / 右汇总常驻 |
| `≥ 1200px` | 三栏 `3 : 5 : 4` | 左日期导航 / 中搜索记录 / 右汇总 |

- 内容最大宽度 `1280px` 居中（超宽屏不要拉长）
- 触控目标最小 `44 × 44px`（手机端）

## 5. 核心组件

### 5.1 当日汇总卡
- 背景：主色填充，圆角 12px，内距 14px
- 第一行：标签「今日摄入」11px
- 第二行：总热量 26px/500 + `kcal` 单位 11px
- 三行营养素：名称 + 克数（左）、供能百分比（右）、下方 5px 进度条
- **进度条表示供能占比，不是完成度**（本产品不设目标值）

### 5.2 餐次卡
- 背景：次级卡片色，圆角 10px，内距 10/12px
- 头部：餐次名 13px/500 + 小计 kcal 11px（右对齐）
- 条目行：食物名 12px + 份量说明 11px 次要色，右侧 kcal 12px
- 行高：手机 44px 以上，便于点按

### 5.3 食物搜索行
- 左侧：名称 12px + 每 100g 数据 10px 次要色
- 右侧：圆形加号按钮 20px，未选中描边、悬停/选中主色填充
- 数据格式：`每 100g · 133 kcal · 碳 2.5 蛋 19.4 脂 5.0`

### 5.4 份量选择（添加食物）
- 份量 chip：圆角 20px，默认描边、选中主色填充
- 手动克数输入：数字输入框，宽度 90px，后缀 `g`
- 实时结果卡：主色填充背景，显示该份量的 kcal + 碳/蛋/脂
- 主按钮：「确认添加」

### 5.5 环形图（供能比）
- SVG `stroke-dasharray` 实现，不用渐变
- 半径 52px、线宽 13px，从 12 点方向顺时针
- 圆心：总热量数字 + `kcal`
- 顺序：碳水 → 蛋白 → 脂肪

## 6. 动画（适度，共 7 处）

| 场景 | 效果 | 时长 | 缓动 |
|---|---|---|---|
| 页面/路由转场 | 淡入 + 上移 6px | 250ms | ease-out |
| 列表项进场 | stagger 逐个淡入上移 | 50ms 间隔 | ease-out |
| 热量数字 | 数字滚动 count-up | 600ms | ease-out |
| 进度条/环形 | 宽度从 0 展开 | 700ms | cubic-bezier(.2,.7,.3,1) |
| 按钮按压 | scale 0.96 | 120ms | ease |
| 添加成功 | toast 淡入上浮 | 300ms | ease-out |
| 主题切换 | 颜色过渡 | 200ms | linear |

> Web 用 Framer Motion，RN 用 Reanimated 3。效果一致，实现两套。
> 尊重 `prefers-reduced-motion`，开启时全部关闭。

## 7. 页面清单

| 页面 | 内容 |
|---|---|
| 登录 / 注册 | 用户名、密码、邮箱（选填）、切换入口 |
| 主界面 | 日期切换 + 汇总 + 当日记录平铺列表 + 右下小 ＋ 入口（三端） |
| 添加食物页 | 独立页面（Web `/add`、App 导航页，非弹窗）：外卖点餐式 = 搜索 + 分类 tab（全部/9类/我的）+ 行内展开份量 + 底部已选条批量记录 |
| 自定义食物 | 分类栏尾部独立「＋ 新增自定义」入口；创建后入「我的」并自动加入已选 |
| 设置 | 主题（亮/暗/跟随系统）、数据来源声明、退出登录 |

## 8. 交互细节

- **日期切换**：左右箭头 +/- 1 天，点击日期打开日历；不允许选择未来日期记录（可放宽）
- **长按/右滑条目**：删除该条记录
- **点击条目**：修改克数或移动餐次
- **空状态**：餐次无内容时显示「添加食物」文字按钮，不用图标堆砌
- **加载态**：骨架屏（食物列表），不用转圈
- **错误态**：内联文字提示，toast 只用于成功反馈
